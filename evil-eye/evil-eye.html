Integration & 2D Architecture Guide

Self-contained 2D vector integrator combining elastic tether tension, Cartesian pointer velocity tracking, and SVG thread rendering.

Full 2D Freedom

Charm position is represented by Cartesian vector $(x, y)$ rather than a 1D scalar angle, allowing free 360° motion.

STEP 2

Vector Tether Forces

Dynamic SVG Thread

// 1. 2D VECTOR PENDULUM / ELASTIC TETHER INTEGRATOR
function step2DPhysics(dt) {
  if (state.isDragging) return;

  // Vector from anchor to charm attachment point
  const dx = state.x - anchor.x;
  const dy = state.y - anchor.y;
  const dist = Math.hypot(dx, dy) || 1;
  const nx = dx / dist, ny = dy / dist; // Unit direction vector

  // Downward gravity force
  let fx = 0;
  let fy = config.gravity;

  // Elastic string tension towards rest length L0
  const deltaL = dist - config.restLength;
  const tension = (deltaL > 0) ? deltaL * config.stiffness : deltaL * (config.stiffness * 0.25);

  // Apply restoring tension along tether line
  fx += -tension * nx;
  fy += -tension * ny;

  // Update 2D velocity & position with damping
  state.vx = (state.vx + fx * dt) * Math.pow(config.damping, dt * 60);
  state.vy = (state.vy + fy * dt) * Math.pow(config.damping, dt * 60);
  state.x += state.vx * dt;
  state.y += state.vy * dt;

  // Render dynamic thread line exactly from anchor to attachment loop
  svgThreadLine.setAttribute('x2', state.x);
  svgThreadLine.setAttribute('y2', state.y);
}
